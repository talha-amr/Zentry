# Zentry

An interactive digital experience that combines bold art direction, layered media, and scroll-driven motion.

[Live experience](https://zentry-phi-blue.vercel.app/) · [View repository](https://github.com/talha-amr/Zentry)

## Overview

Zentry is a creative frontend project built to study advanced landing-page composition and animation. It uses GSAP to connect hero media, feature layouts, storytelling, and typography into one continuous experience.

## Highlights

- Animated hero experience
- GSAP ScrollTrigger interactions
- Split-text typography animation
- Bento-style feature presentation
- Layered story section
- Responsive navigation, contact, and footer
- Reusable component architecture

## Built with

- React 19
- Vite
- Tailwind CSS 4
- GSAP
- ScrollTrigger
- SplitText
- React Use
- React Icons

## Run locally

```bash
git clone https://github.com/talha-amr/Zentry.git
cd Zentry
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
